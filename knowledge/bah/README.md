# Generated BAH Knowledge Corpus

Run `npm run bah:refresh` followed by `npm run bah:index` to create the local priority corpus under `current/`.

Generated snapshots, raw SAP specifications, and the SQLite index are intentionally excluded from Git. They may be large and their retention or redistribution must follow SAP terms and organizational policy.

See [`tools/bah-knowledge/README.md`](../../tools/bah-knowledge/README.md) for the refresh and review process.
